# ExpenseTrack — Full-Stack Expense Management Application

ExpenseTrack is a full-stack expense management application that allows users to securely manage and track their personal expenses.

## Tech Stack

### Frontend

- Angular
- TypeScript
- HTML
- CSS
- RxJS

### Backend

- Node.js
- Express.js
- Mongoose
- JWT
- bcrypt

### Database

- MongoDB Atlas
